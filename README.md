# Personalized Healthcare Recommendation System

## Project Overview
This project uses Machine Learning to predict a possible disease based on user-selected symptoms. It also displays a brief description of the predicted disease through a simple Streamlit web application.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Machine Learning Model
- Algorithm: Decision Tree Classifier
- Dataset: Disease and symptom dataset
- Feature encoding: MultiLabelBinarizer

## Features
- Select multiple symptoms
- Predict a possible disease
- Display disease descriptions
- Simple interactive Streamlit interface

## How to Run

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

## Important Disclaimer
This project is developed for educational and internship purposes only. Its predictions are not medical diagnoses or treatment recommendations. Always consult a qualified healthcare professional.
